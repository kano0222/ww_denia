# ww_denia

《鸣潮》角色“达妮娅（Denia / ダーニャ）”的非官方人物设定资料库。

本仓库整理达妮娅的身份、经历、人物关系和表达方式，目标是提供一份能够查证、方便复用，同时区分明确事实与合理归纳的人物资料。它不限定具体平台，可用于角色扮演提示词、知识库检索、聊天机器人、人物研究及创作参考。

> 仓库包含《鸣潮》3.2、3.3 等剧情的重要剧透。

## 内容

```text
ww_denia/
├── knowledge/
│   ├── identity/       身份、来历与阿列夫一
│   ├── relationships/  残星会、漂泊者及学院内外的人物关系
│   ├── events/         生日同行，以及对过去和未来的看法
│   └── daily/          学院生活、料理与日常偏好
├── persona/
│   └── denia_agent.md  角色扮演与自然交流参考
├── references/
│   ├── provenance.json 结论与原始文本 ID 的对应关系
│   ├── style_examples.md 表达示例的依据与适用情境
│   └── interpretation_notes.md 翻译差异与演绎边界
└── evaluation/
    └── questions.json  事实问题与对话验证情境
```

`knowledge/` 用中文整理人物事实、关系与事件，每个小节尽量能够独立理解。`persona/` 提供少量核心事实、中文表达方式与互动示例。示例属于演绎创作，不冒充官方台词。出处和使用语境集中保存在 `references/`。

## 资料来源

主要数据来源为 [Arikatsu/WutheringWaves_Data](https://github.com/Arikatsu/WutheringWaves_Data) 的 `3.7` 分支，本次整理所依据的提交为：

```text
9218d612ad815e398e064e577e42aaf878899968
```

事实核对主要使用：

- 游戏官方简体中文本地化文本；
- 游戏日文本地化文本；
- 剧情对话及其文本 ID、说话者和上下文；
- 达妮娅角色故事、资料语音、鉴定报告、珍贵之物、特色料理和相关术语说明。

事实以中日原文交叉核对，中文专名沿用官方简体中文本地化；人格表达以日文台词的措辞、态度与互动方式为主要依据，再写成自然中文。两种语言的强调点或含义有差异时保留区别，不把自行翻译当作官方中文。重要结论可通过 `references/provenance.json` 回查文本 ID。

当前演绎依据是文字材料，尚未核实日服音频的声线、语速和实际停顿，也不从声优现实人格推导角色性格。

## 整理方式

资料整理时先从游戏数据中确认原始文本和上下文，再将分散剧情归纳为能够独立理解的人物知识。明确记载的事实、由多段剧情支持的归纳，以及仍未确认的信息会分别表述，不把推测写成确定设定。

知识文档不是对全部台词的转录，也不依赖固定平台的分块方式。原始剧情中无法确认的分支关系、播放顺序和人物来历会保留不确定性。

## 使用建议

[Releases](https://github.com/kano0222/ww_denia/releases) 中的 `达妮娅设定集.zip` 仅收录正文，保留身份、人物关系、事件和日常的分类目录，不含人格、出处索引与验证题。推送 `v` 开头的版本标签时自动生成。

- 需要人物事实时使用 `knowledge/`。
- 需要角色扮演或对话风格时参考 `persona/denia_agent.md`。
- 接入检索系统时，建议先只导入 `knowledge/`，不要把人格提示词和技术溯源混入同一索引。
- 使用 `evaluation/questions.json` 检查事实与多轮互动。静态文件校验不能证明实际检索成功；测试时分别记录工具调用、命中内容与最终回答，不要求模型复述某句示范。
- 不要默认将现实中的使用者视为剧情中的漂泊者，也不要虚构双方共同经历过游戏事件。

## 范围与边界

当前资料集中于达妮娅本人，以及她与阿列夫一、残星会、漂泊者、西格莉卡等对象的直接关系。它不是完整的《鸣潮》世界观百科，也不包含战斗攻略或无关角色资料。

达妮娅的生物学出身、真实出生日期和部分剧情分支仍没有确定答案。仓库会保留这些不确定性，不用二次创作补齐缺失事实。

人格采用她已经承认自己的心、愿意选择并期待普通生活的演绎视角，不补写后续去向或重逢结果。知识文档中的不同剧情阶段、资料语音和人物看法仍分别保留。
